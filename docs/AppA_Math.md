# Engine::Graphics

## Line::Line(Engine::Vec3f (&lineFunction)(float), float start, float end, float interval, float thickness)
This function generates a mesh of a tube using the curve generated by $f(t)$
which is defined as <code>lineFunction(float)</code>. There is math that has been abstracted
and will be explained in this section.

### Setup
- \f$\text{let }\vec{f}(t)\in \mathbb{R}^3, t\in\mathbb{a, b}\f$ is the reference function 
<code>float (&lineFunction)(float)</code>
- \f$a, b \in\mathbb{R}\f$ are parameters <code>float start, float end</code>
- \f$i\in\mathbb{R}\f$ is parameter <code>float interval</code>. In an ideal situation, \f$i=0\f$, but this is a computer
and we can't really compute limits perfectly, so we will assume \f$i\approx0\f$ but it really can equal anything
- \f$c\in\mathbb{R}\f$ is <code>float thickness</code>

### Assumptions
We can not perfectly compute derivatives, but to get as close to the tangent as possible we will use the
following approximation:
$$
\vec{f'}(t)=\frac{\vec{f}(t+i)-\vec{f}(t-i)}{2i}
$$

We will use this derivative to create as close of a tangent line as possible.

### Step 1. Rotation Matrix
we will first determine the angle of each point. We will use the angle formulas to convert from rectangular
to spherical coordinates.

<div>
\f[
\theta(t)=\arctan\frac{f'(t)_y}{f'(t)_x}
\\ \space \\
\phi(t)=\arccos\frac{f'(t)_z}{||f'(t)||}
\f]
</div>

> from here, we will make the abbreviations
> \f$\theta(t) \Rightarrow \theta\f$ and \f$\phi(t) \Rightarrow \phi\f$.
> The goal of this is to avoid cluttering the math as much as possible, 
> but whenever there is a function with \f$t\f$ as a parameter, our angle
> functions will use our \f$t\f$ referenced above 

Now we can create the following rotation matrix:
<div>
\f[
M_R(t)=\begin{bmatrix}
\cos(\phi) & -\sin(\phi) & 0 \\
\sin(\phi) & \cos(\phi) & 0 \\
0 & 0 & 1
\end{bmatrix}\begin{bmatrix}
1 & 0 & 0 \\
0 & \cos(\theta) & -\sin(\theta) \\
0 & \sin(\theta) & \cos(\theta)
\end{bmatrix}
\\ \space \\
\Rightarrow M_R(t)=\begin{bmatrix}
\cos(\phi) & -\sin(\phi)\cos(\theta) & \sin(\phi)\cos(\theta) \\
\sin(\phi) & \cos(\phi)\cos(\theta) & -\cos(\phi)\sin(\theta) \\
0 & 0 & 1
\end{bmatrix}
\f]
</div>

### Step 2. Creating a Ring around an arbitrary point

now that we have our rotation matrix, we can apply this to a point on the ring $r(\alpha)\in\mathbb{R}^3, \alpha\in\mathbb{R}$. Overall, we'll be making ring points with this formula:

$$
\vec{f_r}(t, \vec{dr})=M_R(t)\cdot \vec{dr}+\vec{f}(t)
$$

We do not want to make too many points on each ring, so we will pick four points \f$r_j, j=1, 2, 3, 4\f$ that can be described with our thickness \f$c\f$:
\f[
\vec{r_1}=\langle c, 0, 0\rangle \\
\vec{r_2}=\langle 0, 0, c\rangle \\
\vec{r_3}=\langle -c, 0, 0\rangle \\
\vec{r_4}=\langle 0, 0, -c\rangle \\
\f]

We can then abstract the work to get the following ring around an abstract point:

\f[
\vec{f_r}(t, \vec{r_1})=M_R(t)\cdot\vec{r_1}+\vec{f}(t)
=\langle\cos(\phi)t, \sin(\phi)t, 0\rangle + f(t) \\

\vec{f_r}(t, \vec{r_2})=M_R(t)\cdot\vec{r_2}+\vec{f}(t)
=\langle\sin(\phi)\sin(\theta)t,-\cos(\phi)\sin(\theta)t, \cos(\theta)t\rangle + f(t) \\

\vec{f_r}(t, \vec{r_3})=M_R(t)\cdot\vec{r_3}+\vec{f}(t)
=\langle-\cos(\phi)t, -\sin(\phi)t, 0\rangle + f(t) \\

\vec{f_r}(t, \vec{r_4})=M_R(t)\cdot\vec{r_4}+\vec{f}(t)
=\langle\sin(\phi)\sin(\theta)t, -\cos(\phi)\sin(\theta)t, \cos(\theta)t\rangle + f(t) \\
\f]
