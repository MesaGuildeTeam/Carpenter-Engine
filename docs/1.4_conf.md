# 1.4: Workspace Config File

When setting up your workspace, you can create an optional file called
`tableconf.json`. This file lets you configure not only your workspace, but
also the the setup required to make sure your game is compiled and packaged
as convenient as possible.

## Basic Parameters

### `name`

This is your game's name...

## Development Parameters

### `inputPath`

This is the path to your game's source code, i.e. your `.cpp` and `.hpp` files.

### `outputPath`

This is where your `.o` files get compiled to. this folder by default is called
`objs`.

### `framworkPath`
This is the path to your `carpenterengine.a` file which is Carpenter Engine's Precompiled code

### `includeDir`
If you have any external header files you want to include in your project directory, you can add a folder to your project.

### `static`
This is the directory to your static html data. Carpenter Engine already includes
one, but you are free to prepare your own based on the provided code.
