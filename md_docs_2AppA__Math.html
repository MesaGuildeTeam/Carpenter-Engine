Assumptions

We can not perfectly compute derivatives, but to get as close to the tangent as possible we will use the following approximation: $$ \vec{f'}(t)=\frac{\vec{f}(t+i)-\vec{f}(t-i)}{2i} $$

We will use this derivative to create as close of a tangent line as possible.
